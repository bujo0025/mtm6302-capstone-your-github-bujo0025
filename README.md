Capstone Part-3 Report:
This project is a prototype webpage that allows users to explore NASA’s Astronomy Picture of the Day by selecting a date. The webpage was built using HTML, CSS, and JavaScript, featuring a modern dark theme. A date picker was added to let users choose any date, and the app fetches image data, titles, and descriptions from NASA’s APOD API using the fetch() method. During development, I referred to NASA’s API documentation for guidance on API integration and styling. Some challenges included fetching data correctly with the API key, handling different media types (images and videos), and maintaining consistent dark theme styling. Overall, the project provided hands-on experience working with APIs, asynchronous JavaScript, and responsive design principles.

This project was built to create a simple and interactive way to explore NASA’s Astronomy Picture of the Day.
